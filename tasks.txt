PHASE 1 — CORRECTNESS AND RELIABILITY BUGS
==========================================

SUBTASK 1.1 — VOICE INFLIGHT TOOL LEAK

Inspect:

backend/app/voice/session.py

Current behavior:

handle_function_call_request() adds func_id to inflight_tool_ids before executing the tool.

The ID is discarded only on the successful path.

If parsing or tool execution raises, the outer exception handler sends an error but does not reliably remove the function ID.

Fix:

* isolate error handling per function call
* ensure inflight_tool_ids.discard(func_id) happens in finally
* one failed function must not prevent remaining functions in the same FunctionCallRequest from being processed
* preserve duplicate/reconnect idempotency protections
* cache safe completed error responses when appropriate so provider reconnect does not repeatedly invoke broken mutations

Tests:

* tool succeeds
* tool raises
* malformed arguments
* two functions where first fails and second succeeds
* reconnect after failed function
* duplicate mutation request

Acceptance criteria:

No function ID remains inflight after its execution has terminated.

SUBTASK 1.3 — TWILIO TASK RETRY CLASSIFICATION

Current risk:

Redesign booking into:

* provider timeout
